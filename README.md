# 👥 User Manager

A user profile manager with full CRUD (Create, Read, Update, Delete) built with HTML, CSS, and vanilla JavaScript. Data is saved in the browser, so it stays after a refresh.

## ✨ Features

- Create a user with name, email, and profile image URL
- View all users as cards
- Update an existing user using the same form
- Delete a user
- Data saved with `localStorage`
- Default avatar when no image is given
- Glassmorphism UI with a modal form
- Responsive design for mobile and desktop

## 🧠 Concepts Practiced

- Form handling with the `submit` event and `preventDefault()`
- CRUD operations on an array of objects
- Saving and loading data with `localStorage` and `JSON`
- Rendering UI from data with template strings
- Opening and closing a modal by toggling a CSS class

## 🛠️ Built With

- HTML5
- CSS3 (Grid, `backdrop-filter`)
- JavaScript (DOM manipulation)

## 🚀 How to Run

1. Clone this repository
   ```bash
   git clone https://github.com/rahulgavel73/CRUD_project.git
   ```
2. Open the `user-manager` folder
3. Open `index.html` in your browser

No installation needed.
